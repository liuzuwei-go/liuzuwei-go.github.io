电信号 ​

什么是电信号 ​

信号是反映消息的物理量，消息需要借助于某些物理量（如声、光、电）的变化来表示和传递，在电子电路中的信号均为电信号。

模拟信号和数字信号 ​

信号的形式是多种多样的，在电子电路中则将信号分为模拟信号和数字信号。模拟信号在时间和数值上具有连续性，数字信号在时间和数值上具有离散性。

电子信息系统 ​

模拟电子系统的组成 ​

无数字系统参与

  1. 提取：从各种能产生电信号的设备中采集信号
  2. 预处理：利用隔离、滤波、阻抗变换等技术将信号分离并放大
  3. 加工：对信号采用运算、转换、比较、采样保持等不同的加工
  4. 驱动与执行：驱动执行机构

有数字系统参与（常用）

  1. 提取：从各种能产生电信号的设备中采集信号
  2. 预处理：利用隔离、滤波、阻抗变换等技术将信号分离并放大
  3. 加工：对信号采用运算、转换、比较、采样保持等不同的加工
  4. A/D转换：将模拟信号转换为数字信号
  5. 数字系统：对数字信号进行处理
  6. D/A转换：将处理后的数字信号转换为模拟信号
  7. 驱动与执行：驱动执行机构

电子信息系统的组成原则 ​

  1. 必须满足功能和性能指标要求
  2. 电路要尽量简单，集成电路能实现的不选用分立元件电路，大规模集成电路能实现的不选用小规模集成电路
  3. 电磁兼容性，在预定环境下能够抵御周围电磁场的干扰且较少的影响周围环境
  4. 可测性，合理引出测试点，设计自检电路

电子信息系统中的常用的模拟电路 ​

  1. 放大电路：用于信号的电压、电流或功率放大
  2. 滤波电路：用于信号的提取、变换或抗干扰
  3. 运算电路：对信号进行运算
  4. 信号转换电路：不同形式的信号的转换，如电压信号和电流信号、直流信号和交流信号等
  5. 信号发生电路：用于产生正弦波、矩形波、三角波、锯齿波等不同信号
  6. 直流电源：将家用或工业交流电转换成直流电，作为电子电路的供电电源
